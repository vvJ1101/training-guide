一、市场部

责任人：市场部 ｜ 文档：联欣&康雷系统操作手册 V2、客户报名&订货流程

Q1: 云仓、现货、期货怎么区分？订单审核时最容易错在哪里？

在联欣后台「主题订单」页面，根据订单主题类型设置标签，这是最关键的步骤：

  • 云仓：实时库存，下单即有货可发
  • 现货：现货库存，需要商品部截单日统一截单
  • 期货：需要生产周期，品牌下单后才生产

严禁云仓主体与期货/现货标签混淆，一旦设错，订单推送到康雷后流程全乱。

Q2: 云仓订单的完整操作流程是什么？

3 步走：

  1. 检查渠道订单：确认订单号、客户名称、商品信息与联欣一致
  2. 回款登记：在【回款单管理】菜单找到对应回款单 → 编辑，填写付款方式、收款金额，上传付款凭证 → 保存后提交自行审核（云仓由提交人自行审核，无需财务介入）
  3. 提交出货指令单：核对收件地址等信息，无误后提交，品牌即可发货

云仓不需经过商品部截单和转发货操作。

Q3: 回款单填写有什么规范？为什么会被退回？

三个必填项缺一不可：

  • 客户付款方式（银行转账/微信/支付宝等）
  • 收款金额
  • 付款凭证截图（必须清晰完整）

信息填写不规范将被财务退回，影响发货时效。

含运费/税费的特别处理：回款金额须与订单金额一致。若回款包含了运费或税费，多余部分会自动转入客户余额。需在对应渠道订单下点击「增加费用」→ 制作应收费用单冲减运费/税费。

Q4: 现货订单我（市场部）需要做什么？和云仓有什么区别？

实际上你只需要做一件事：回款登记。

现货完整链路是：联欣审核 → 同步康雷 → 商品部截单日统一截单转采购 → 你（市场部）做回款登记（提交财务审核）→ 商品部提交出货指令 → 品牌发货。

区别：云仓：自行审核回款 现货：提交财务审核回款，且你不接触发货指令。

Q5: 期货订单的操作流程？订金和尾款分别怎么处理？
  • 收订金（期货下单后）：通过渠道订单号查找订金收入单 → 编辑 → 选择付款方式 → 保存提交
  • 收尾款（品牌生产完毕可发货时）：统一使用「转回款」操作——在【渠道订单】页面找到对应订单，点击「转回款」按钮 → 选择付款方式、填写收款金额、上传凭证 → 提交。该操作会生成对应的回款单。

期货完整链路：联欣审核 → 商品部截单转采购 → 你收订金 → 品牌生产 → 你收尾款 → 财务审核 → 商品部转发货。

Q6: 余额支付和余额充值怎么操作？

余额支付（使用已有余额抵扣货款）：

  • 余额充足（整单用余额）：在【渠道订单】页面勾选对应订单 → 点击「余额转入」按钮 → 进入【应收余额转账单】界面 → 选择客户余额账号 → 输入支付额度 → 上传余额使用截图 → 保存提交
  • 余额不足（混合支付）：余额部分做「余额转入」抵扣单 + 现金部分做回款单（一张回款单 + 一张余额转账单）

余额充值（客户往余额账户充钱）：

  • 新建回款单 → 选择品牌余额账号（账号必须与品牌严格对应，如 YEE SILS089 对应 YEE S 品牌）→ 填支付方式、充值金额、上传凭证 → 提交财务审核
Q7: 客户要退换货/取消订单怎么处理？

严禁市场部私自与品牌沟通退换货！不经过系统处理会导致商品部和财务部月结核算数据不准确。

所有删除操作前需在【单据反审核】模块中先完成反审核，否则无法删除。

场景操作
换同等金额款式线下联系商品部换货，无需系统操作
换款后有差额市场部在联欣重新下单 + 商品部在康雷做退货处理
云仓未发货取消（退款）删除三张单据：出货指令单 → 回款单 → 渠道订单
云仓未发货取消（存售后款）仅删除出货指令单，通知商品部将订单标记为完成
使用余额支付订单取消删出货指令单 + 渠道订单 → 做反向应收余额转账单将余额转回
已发货退货联系商品部做退货处理（所有取消都必须经商品部）

二、商品部

责任人：商品部 ｜ 文档：康雷&联欣系统操作手册 V2、联欣系统操作手册

Q1: 截单转采购（期货/现货）的具体操作步骤？
  1. 在康雷「渠道订单」模块，筛选品牌、截单时间段
  2. 跟市场部核对订单数据，无误后批量勾选订单
  3. 点击「转采购」→ 系统自动生成采购单
  4. 检查采购单数量和金额，确认无误后提交
  5. 通过采购单报表导出明细发给品牌方，通知生产

云仓订单不需要经过截单，自动生成出货指令单。

Q2: 期货转预付款怎么做？和钉钉 OA 怎么衔接？
  1. 期货订单截单转采购后，在【采购单】列表找到对应的采购单
  2. 点击「转预付款」按钮 → 进入【预付款】界面，填写本次采购金额的 50% 订金
  3. 预付款单据保存后，将单号同步到钉钉 OA 流程，告知财务预付款单号
  4. 财务审批付款并提交预付款单据
Q3: 转发货怎么操作？期货和现货有什么区别？

期货转发货：

  1. 品牌通知库存到位 → 商品部通知市场部收尾款
  2. 市场部回款单通过财务审核后，在渠道订单上点击「转发货」
  3. 选择品牌仓库 → 检查出货指令单明细（可右键删除本次不发的货号）
  4. 点击「订金结转」（渠道订单订金比例 100% 则结转 100%；50% 且有回款单则结转 50%）
  5. 提交出货指令单，通知品牌发货

现货转发货：

  1. 品牌通知库存到位 → 找到渠道订单点击「转发货」
  2. 100% 金额结转成货款 → 提交出货指令单通知品牌发货

云仓不用商品部转发货，由市场部直接提交。

Q4: 新品牌上线需要在康雷和联欣分别建哪些档案？

康雷系统（ERP）：

  • 货品资料：权限分类、货号、吊牌价、品牌分类、尺寸组、颜色等
  • 条形码：系统自动生成（货号+颜色编号+尺码）或 Excel 批量导入
  • 仓库资料：权限分类与品牌一致。云仓仓库编号 = 供应商编号；现货期货仓库编号 = 供应商编号-1；区域选「品牌直发仓」
  • 供应商档案：编号与云仓仓库编号一致，设置采购价比例

联欣系统：

  • 字典管理 → 新建仓库（编号与康雷一致。注意：只需建云仓仓库，期货现货不需要建）
  • 款式属性 → 添加新品牌信息
  • 主题管理 → 新建主题 → 关联商品 → 设置小程序展示
Q5: 条形码的生成规则和批量导入方法？
  • 自动生成规则：货号 + 颜色编号 + 尺码
  • 生成步骤：条形码管理 → 点击「生成条形码」→ 选择生成规则 → 预览 → 系统汇总所有需要建立条形码的货号明细 → 点击保存确定
  • Excel 批量导入：在 Excel 整理好商品的颜色、尺码后，直接从文件批量导入条码
  • 涉及聚水潭同步库存的品牌，商品资料需在「条形码对应」做导入对应关系
Q6: 反审核删单的正确顺序是什么？三种订单各有什么区别？

核心原则：反审核顺序是做单顺序的逆向操作。所有删除操作前，必须先在【单据反审核】模块完成反审核。

订单类型正向顺序（做单）反审核逆向顺序（删单）
云仓渠道订单 → 回款单 → 出货指令单出货指令单 → 回款单 → 渠道订单
现货渠道订单 → 回款单 → 出货指令单回款单 → 出货指令单 → 渠道订单
期货渠道订单 → 订金收入单 → 回款单 → 出货指令单 → 订金转货款订金转货款 → 订金收入单 → 出货指令单 → 回款单 → 渠道订单
Q7: 同一订单需要分批多次发货（二次配货）怎么操作？
  1. 按货号查找未发完货的订单号
  2. 勾选需要发货的订单，点击「转发货」
  3. 生成出货指令单 → 保存后提交 → 通知品牌方发货
  4. 如后续还需发货，与品牌方沟通后重复以上步骤，商品部再次推送发货单
Q8: 想删除单据（删单），系统提示不让删怎么办？

所有单据删除前，必须先在【单据反审核】模块中完成反审核。这是删单的前置条件，缺此步骤系统会阻止删除。

操作路径：系统菜单 → 【单据反审核】→ 找到对应单据 → 反审核 → 回到对应模块按顺序删除。

反审核的逆向顺序参见上方 Q6 的删单顺序表。

三、品牌部（内部）

适用对象：本公司品牌部同事 ｜ 文档：品牌部-查看订单数据手册 ｜ 注意：以下操作均在联欣系统

Q1: 怎么看各品牌的意向订单和购物车数据？

路径：联欣 →「购物车管理」。可按以下方式导出：

  • 汇总导出：整体概览
  • 一维导出：按订单维度展开
  • 二维导出：按店铺+商品维度展开
Q2: 怎么按时间段查询各品牌确认订单？

路径：联欣 →「订货客户汇总-市场部」→ 筛选时间、品牌 → 订单状态勾选「发货」和「已完成」→ 点击查询导出。

Q3: 订单汇总分析怎么设置维度？

路径：联欣 →「汇总分析」→ 筛选品牌、时间、订单状态 → 选择一级分析维度（如品牌、时间）和二级分析维度（如客户、地区）→ 点击查询。

常用维度组合：品牌+客户 / 品牌+月份 / 客户+商品类型。

Q4: 怎么按店导出各品牌每个客户的订单明细？

路径：联欣 →「主题订单」→ 筛选品牌、订单状态（发货、已完成）、时间 → 点击查找 → 选择二维按店导出。

Q5: 怎么查看商品排行和各店铺单品的销售情况？

路径：联欣 →「货品排行」→ 从货品资料中添加需要的维度（如品牌、时间范围、订单状态等）→ 系统按维度展示各品牌商品销售排名和各店铺单品销售数据。

四、财务部

责任人：财务部 ｜ 文档：财务部-康雷系统财务对帐说明 V2

Q1: 回款单审核的三个关键检查点是什么？
  • 付款金额：与订单金额是否一致
  • 付款方式：银行转账/微信/支付宝/余额支付等
  • 付款凭证截图：是否清晰完整，与付款方式、金额匹配

余额全款支付：只做一张余额支付的回款单；余额不足混合支付：一张余额支付回款单 + 一张实际支付回款单。

Q2: 余额支付的回款单怎么审核？混合支付怎么处理？
支付情况单据组合审核要点
余额全额支付1 张余额支付回款单余额截图 + 余额账户 + 支付金额
余额 + 现金混合1 张余额抵扣单 + 1 张现金回款单两份凭证分别对应余额和现金部分，合计等于订单金额
Q3: 预付款和应付付款单有什么区别？各在什么阶段操作？
单据金额时机操作人
预付款采购单金额的 50%（品牌订金）期货截单转采购后商品部建单 + 财务部付款提交
应付付款单全款云仓 + 全款现货 + 50% 期货尾款每月品牌结算时商品部建单 + 财务部付款提交
Q4: 应付核算（月结）怎么操作？
  1. 商品部根据系统发货明细，核对上月发货明细，跟品牌确认结算款后新建应付付款单
  2. 财务部通过「应付核算」功能核对商品部提交的钉钉付款申请：
    • 期货/现货费用类型体现为「采购收货单」
    • 云仓费用类型体现为「仓库出货单」
    • 运费等体现为「应付费用单」（正数增加应付、负数减少应付）
    • 期货订金体现为「预付款」
  3. 所有单据叠加计算后为本期应付总额
  4. 月结付款后核实无误 → 点击「应付核算」生成本期账单 → 封帐结存
Q5: 应付核算数据对不上怎么排查？

分三条线交叉核对：

  1. 渠道订单报表：按店铺区域筛选出区域订单进行统计
  2. 收渠道退货单报表：客户退货、换货有差额的都在此报表体现
  3. 应收费用单：确认运费/税费是否已正确冲减

最大隐患：退换货未经过系统处理（私下操作），这会导致两套数据对不上。

Q6: 怎么查看每个客户的回款情况？

路径：康雷 → 「订单回款跟踪报表」→ 可按店铺区域筛选 → 选择该区域店铺 → 查看每个客户订单的具体回款明细（回款金额、回款方式、凭证状态）。
