合作品牌方操作指南

康雷 ERP 系统 — 采购对接 · 库存维护 · 出货发货 · 报表查阅

Q1: 怎么查看 YUAN 发给我们的采购单明细？

路径：商品中心 → 采购管理 → 采购单 → 双击打开单据 → 在「商品信息栏」可以看到具体的采购明细和数量。

这些采购单是 YUAN 根据客户订单截单后下给品牌方的采购任务，商品部会在截单后导出采购订单同步给品牌方。

Q2: 没有用聚水潭的品牌，怎么手动维护云仓库存？

路径：仓务中心 → 盘点和结存 → 库存调整单 → 点击「新建」。

两种录入方式：

  • 手动输入：光标点击商品编号输入框 → 输入款号 → 按回车 ↩ → 弹出颜色尺码选择界面 → 填入该款号的颜色和尺码
  • Excel 批量导入：点击「导入」→ 下载导入模板（货品模板或条形码模板）→ 填好后导入

录入完成后点击保存、提交。数量填正数为增加，填负数为减少。

Q3: 用聚水潭同步云仓库存的品牌，怎么完成对接？
  1. YUAN 在聚水潭上发起邀请，邀请品牌方成为 YUAN 的供应商
  2. 品牌方点击链接接受合作，开启「库存同步」选项，把库存同步给 YUAN
  3. 设置供应商分销价格、库存规则
  4. 将云仓库存上传到聚水潭的库存管理

品牌提供的资料必须与聚水潭系统里的资料一致（商品、颜色、尺码、商品编码），否则无法同步。

同步完成后，云仓库存会实时反映在 YUAN 的康雷系统以及前端订货小程序。

Q4: 怎么查看待发货的任务？在哪里找到出货指令单？

两种方式都可以：

  • 方式一（推荐）：仓务中心 → 仓库工作台 → 查看「出货渠道指令单」→ 点击「处理」引用 YUAN 的出货指令来发货
  • 方式二：仓务中心 → 仓库出货单 → 待完成单据界面 → 筛选发货店铺、发货类型 → 点击「处理」发货

出货指令单是 YUAN 商品部创建后推送过来的，品牌方根据这个指令做发货动作。

Q5: 照单全发和按实际发的区别？具体怎么操作？
方式适用场景操作
照单全发指令单上的货全部可以发出点击「是」→ 检查款号、尺码、数量 → 保存提交
按实际发（拆单）货不全，先发一部分点击「是」→ 勾选本次不发的款号 → 右键删除 → 剩下部分保存提交

拆单后未发完的部分，后续需要再发货时，与商品部沟通再次推送发货单。

Q6: 发货后快递单号在哪里填？漏填了怎么办？

单据提交保存后 → 在单据详情中找到物流信息栏 → 填写快递单号和物流公司 → 保存后即完成发货。

漏填的可以在已发货的历史发货单数据中，双击打开单据详情补填物流信息。

Q7: 系统里有 5 张报表，各有什么用？
报表名称用途
仓库库存报表查看本品牌的库存情况
采购单报表查看 YUAN 下达的采购任务，可导出具体采购明细
仓库出货单报表查看本品牌给客户发的货品明细（历史发货记录）
配出差异报表查看 YUAN 出货指令 vs 品牌实际发货数量的差异
渠道订单报表查看 YUAN 已审核的客户订单数据

所有报表操作：选择筛选条件 → 选择输出信息 → 点击「统计」查看数据。
