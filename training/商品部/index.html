📖 商品部核心术语（新人先看这里）
术语说明
截单在渠道订单模块按品牌和时间段筛选订单，批量转为采购需求
转采购截单后生成采购单的操作，采购明细会导出通知品牌方生产/备货

2. 订单类型对比：云仓 / 现货 / 期货

责任人：商品部

对比维度云仓现货期货
商品部核心操作 仅检查数据，无需截单和转发货 截单→等回款→转发货 截单→付预付款→等尾款→转发货
是否截单 无需截单 需要截单转采购 需要截单转采购
转发货触发条件 市场部自行转发货 回款审核通过后转发货 尾款收齐且财务审核后转发货
生成单据 渠道订单 + 出货指令单 + 100%回款单 渠道订单 + 回款单 + 出货指令单 渠道订单 + 50%订金收入单
订金结转 不涉及 100%结转 按订金比例结转（50%或100%）

3. 云仓订单处理

责任人：商品部

⚡ 商品部职责：检查渠道订单数据即可，无需截单和转发货（市场部自行处理回款和提交出货指令）
  1. 云仓单自动生成渠道订单、出货指令单、100%回款单
  2. 检查康雷生成的渠道订单数量、金额与联欣是否一致

    ▲ 云仓订单流程总览

    ▲ 检查渠道订单数量金额与联欣是否一致

  3. 检查出货指令单上的收件人信息是否正确，确认无误后提交单据通知品牌方发货

    ▲ 检查出货指令单收件人信息

4. 现货订单处理：截单转采购 → 转发货

责任人：商品部

⚡ 现货 3 步走：① 截单转采购 → ② 等待回款审核通过 → ③ 转发货并提交出货指令

4.1 截单转采购

品牌通知库存到位后，可以安排客户现货订单配发货：

  1. 通过渠道订单模块筛选品牌、截单时间段
  2. 与市场部核对订单数据无误后，操作转采购
现货截单操作界面与期货截单完全一致，参见 第5节 期货截单转采购 的截图。

▲ 现货订单业务流程

4.2 转发货

财务审核通过回款单后，才能提交出货指令：

  1. 找到相应渠道订单，点击转发货

    ▲ 找到渠道订单点转发货

  2. 选择出货的品牌仓库，检查出货指令单的数量和金额，有需要调整明细的可勾选货号后右键删除

    ▲ 选择仓库，检查数量和金额

  3. 100%的金额结转成货款后，提交出货指令单通知品牌发货

    ▲ 提交出货指令单通知品牌发货

5. 期货订单处理：截单转采购 → 预付款 → 转发货

责任人：商品部

⚡ 期货 5 步走：① 截单转采购 → ② 生成采购单导出给品牌 → ③ 付50%预付款 → ④ 等待品牌生产完毕+尾款收齐 → ⑤ 转发货并订金结转

5.1 截单转采购

  1. 期货订单只生成渠道订单和50%订金收入单，需商品部截单转采购后通知品牌生产

    ▲ 期货订单业务流程总览

  2. 通过渠道订单模块筛选品牌、截单时间段，与市场部核对数据无误后操作转采购

    ▲ 渠道订单模块筛选品牌和截单时间

    ▲ 订单审核无误后批量转采购单

  3. 生成采购单，检查无误后提交，通过报表把明细分品牌导出并发送给品牌通知生产

    ▲ 生成采购单并导出采购明细

5.2 支付品牌预付款

  1. 在康雷对应品牌采购单列表找到采购单，点击转预付款
  2. 填写本次采购金额的50%订金，按照钉钉 OA 流程填写对应内容

    ▲ 采购单转预付款

  3. 预付款单据保存后，将单号同步到钉钉 OA 申请流程告知财务预付款单号，财务审批付款并提交

    ▲ 预付款单据保存后同步钉钉 OA

5.3 转发货（品牌生产完毕、客户尾款收齐后）

  1. 品牌期货库存到位后通知 YUAN 商品可配货，商品部通知市场部收取客户尾款

    ▲ 期货订单转发货流程

  2. 市场部回款单经财务审核通过后，点击渠道订单上的转发货，生成出货指令单

    ▲ 市场部回款审核通过后操作转发货

  3. 选择出货品牌仓库后，检查出货指令单的数量和金额，需调整明细的勾选货号右键删除

    ▲ 选择出货仓库并调整明细

  4. 保存后回到单据列表，点击订金结转

    ▲ 保存后点订金结转

  5. 根据渠道订单显示的订金比例确定结转比例：
    • 订金比例为100%的 → 结转比例为 100%
    • 订金比例为50%且有对应回款单的 → 结转比例为 50%

    ▲ 根据订金比例确定结转比例

  6. 订金结转后提交出货指令单通知品牌方发货

    ▲ 订金结转后提交出货指令单

同一订单部分商品首批未发完，后续补发时：

  1. 按货号查找出未发完货的订单号

    ▲ 按货号查找未发完货的订单

  2. 选择需要发货的订单，点击转发货

    ▲ 选择订单点转发货

  3. 后续操作（生成出货指令单、检查明细、保存提交）与首次转发货一致，参见 第4节 或 第5节

7. 订单反审核与删单

责任人：商品部

反审核流程为做单顺序的逆向操作，删除单据必须按顺序反审核。
订单类型删除顺序（从前往后）
云仓① 出货指令单 → ② 回款单 → ③ 渠道订单
现货① 回款单 → ② 出货指令单 → ③ 渠道订单
期货① 订金转货款 → ② 订金收入单 → ③ 出货指令单 → ④ 回款单 → ⑤ 渠道订单

▲ 反审核单据删单操作

8. 客户退货与换货处理

责任人：商品部

8.1 换货

  • 同款同金额换货：直接线下与品牌沟通寄换，无需系统操作
  • 换不同款/不同金额：市场部重新在联欣下单，商品部在康雷做退货处理

8.2 退货

⚡ 操作路径：康雷 → 渠道采购退货指令单 → 填写退货信息 → 录入退货明细 → 保存提交
  1. 在康雷系统做渠道采购退货指令单
  2. 填写退货的品牌、退货店铺，手工单号填写原渠道订单号
  3. 录入退货明细（注意退货价与采购价的区别：一个是客户订货价，一个是采购退货价）
  4. 保存提交

▲ 渠道采购退货指令单操作

8.3 订单取消（已付订金品牌没货发）

对于期货已付订金但品牌没货需要取消的情况，制作采购退货单，整张采购单的付款金额为取消款的订金金额。

11. 附录：系统基础建档速查

以下内容仅在首次配置或新增品牌时涉及，日常操作可跳过。
建档大类建档项关键说明
货品基础货品资料新增货号需填写：货号、名称、吊牌价、分类、品牌、权限分类、折扣类型、尺寸组、颜色、规格等；支持 Excel 批量导入
条形码系统按"货号+颜色编号+尺码"自动生成；聚水潭品牌需在条形码对应做 Excel 导入
图片信息由货品图片上传工具操作，支持批量/单个上传
分类体系权限分类按品牌创建，控制角色/用户可见范围
货品分类多级分类，新增/导入商品时须关联
货品时间分类三级：年份 → 季节 → 上市波段
尺码/颜色/规格按需建立尺寸组、颜色组；规格默认0，用于西服版型/文胸罩杯等
仓库/供应商仓库资料云仓仓库编号=供应商编号；现货/期货编号后加-1；区域选"品牌直发仓"
供应商档案供应商编号=品牌云仓仓库编号，权限分类=品牌权限分类
结算户口/店铺联欣推送自动创建，户口编号=客户手机号
